Help & Rules

Using this game

  • All games returns to the home screen to switch between Chess and Sudoku.
  • Tap a cell to select it. Related row, column, and box are highlighted.
  • Enter a number with the on-screen pad or keys 1–9.
  • Erase clears the selected cell (or press Backspace / Delete / 0).
  • Given clue numbers (darker cells) cannot be changed.
  • Conflicts turn red when the same number repeats in a row, column, or 3×3 box.
  • When the grid matches the solution, status shows Solved! and the timer stops.

Sudoku rules

The goal

Fill the 9×9 grid so that every row, every column, and every 3×3 box contains the digits 1 through 9 exactly once.

Clues

Some cells start filled. Those are clues. Keep them and fill the empty cells around them.

Difficulty

Easy leaves more clues, Medium removes more, Hard removes the most. Each new puzzle is generated with a unique solution.

Buttons & keys

  • New puzzle — generate a fresh grid at the current difficulty.
  • Check — reports how many cells are wrong or still empty.
  • Hint — fills one empty cell with the correct number.
  • Erase — clears your selected (non-clue) cell.
  • 1–9 — place that digit in the selected cell.
  • Arrow keys — move the selection around the board.
  • Escape — closes this help panel.

Helpful tips

  • Scan singles — if a cell has only one possible digit, place it.
  • Use boxes — look at a 3×3 box and see where a missing digit must go.
  • Cross-hatch — for a digit, mark rows/columns that already have it, then find the open spot in a box.
  • Don’t guess early — on Medium/Hard, forced moves usually exist before you need trial and error.
  • Check often — Catch mistakes early with Check before the grid fills up.
  • Hints sparingly — use Hint when stuck, then try to understand why that number fits.
